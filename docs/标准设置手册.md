# R3G OpenWrt 标准设置手册

> 基于本机成功案例，适用于全新刷机后的一键还原。  
> 固件：OpenWrt 23.05.x | 设备：Xiaomi R3G  

---

## 一、硬件接线标准

```
R3G WAN口 → 上级交换机/路由器 LAN口
R3G LAN口 → 留空！
```

> 严禁 WAN + LAN 同时接交换机，会产生二层环路导致全网瘫痪。

---

## 二、网络配置（UCI）

```bash
# LAN — 静态 IP，作为旁路由网关
uci set network.lan.proto='static'
uci set network.lan.ipaddr='192.168.1.1'
uci set network.lan.netmask='255.255.255.0'
uci set network.lan.ip6assign='60'

# WAN — DHCP 自动获取上游 IP
uci set network.wan.proto='dhcp'

# 应用
uci commit network
/etc/init.d/network restart
```

## 四、DHCP 配置（UCI）

```bash
# dnsmasq 基础
uci set dhcp.@dnsmasq[0].authoritative='1'
uci set dhcp.@dnsmasq[0].localservice='1'
uci set dhcp.@dnsmasq[0].local='/lan/'
uci set dhcp.@dnsmasq[0].domain='lan'
uci set dhcp.@dnsmasq[0].cachesize='1000'
uci set dhcp.@dnsmasq[0].nonwildcard='1'
uci set dhcp.@dnsmasq[0].ujail='0'           # 必须禁用 ujail

# LAN DHCP 池
uci set dhcp.lan.interface='lan'
uci set dhcp.lan.start='100'
uci set dhcp.lan.limit='150'
uci set dhcp.lan.leasetime='12h'
uci set dhcp.lan.dhcpv4='server'

# WAN 不提供 DHCP
uci set dhcp.wan.ignore='1'

# odhcpd 只管 IPv6，不抢 IPv4 DHCP
uci set dhcp.odhcpd.maindhcp='0'

uci commit dhcp

# 禁用 ujail（修改 init 脚本）
cp /etc/init.d/dnsmasq /etc/init.d/dnsmasq.bak
sed -i 's/^\tprocd_add_jail dnsmasq ubus log$/\t#procd_add_jail dnsmasq ubus log/' /etc/init.d/dnsmasq
sed -i 's/^\tprocd_add_jail_mount/\t#procd_add_jail_mount/' /etc/init.d/dnsmasq
sed -i 's/^\tprocd_add_jail_mount_rw/\t#procd_add_jail_mount_rw/' /etc/init.d/dnsmasq

/etc/init.d/dnsmasq restart
```

## 五、防火墙配置（UCI）

```bash
# 默认策略
uci set firewall.@defaults[0].input='REJECT'
uci set firewall.@defaults[0].forward='REJECT'

# LAN 区域 — 全放行
uci set firewall.@zone[0].name='lan'
uci add_list firewall.@zone[0].network='lan'
uci set firewall.@zone[0].input='ACCEPT'
uci set firewall.@zone[0].output='ACCEPT'
uci set firewall.@zone[0].forward='ACCEPT'

# WAN 区域 — 入站拒绝，出站放行，开启 NAT
uci set firewall.@zone[1].name='wan'
uci add_list firewall.@zone[1].network='wan'
uci add_list firewall.@zone[1].network='wan6'
uci set firewall.@zone[1].input='REJECT'
uci set firewall.@zone[1].output='ACCEPT'
uci set firewall.@zone[1].forward='REJECT'
uci set firewall.@zone[1].masq='1'

# LAN → WAN 转发
uci set firewall.@forwarding[0].src='lan'
uci set firewall.@forwarding[0].dest='wan'

uci commit firewall
/etc/init.d/firewall restart
```

## 六、透明代理配置

### 6.1 nftables 规则（shellcrash 表）

安装 ShellClash 后，需确保生成的 `nft list table inet shellcrash` 规则中：

- **input 链**：仅 `lo` 和 `br-lan` 可访问 7890/9999，其他来源拒绝
- **prerouting_dns 链**：DNS(UDP/TCP 53) 从 `br-lan` 进入时重定向到 `:1053`
- **prerouting 链**：TCP/UDP 流量从 `br-lan` 进入时打 fwmark `0x1ed4`

关键匹配条件必须是 `iifname br-lan`（非 `ip saddr`），以兼容任意 IP 的客户端。

### 6.2 策略路由

```bash
ip rule add fwmark 0x1ed4 table 100
ip route add default dev utun table 100
```

### 6.3 mihomo config.yaml 关键段

```yaml
mixed-port: 7890
mode: Rule
allow-lan: true
ipv6: true

tun:
  enable: true
  stack: system          # mips 平台必须 system
  device: utun
  auto-route: false      # 由 nftables 手动控制
  auto-detect-interface: false

dns:
  enable: true
  listen: :1053
  enhanced-mode: fake-ip
  fake-ip-range: 28.0.0.0/8
  default-nameserver: [223.5.5.5]

routing-mark: 7894
```

## 七、验证清单

刷完配置后逐项确认：

| 检查项 | 命令 | 预期 |
|--------|------|------|
| WAN 获取 IP | `ip addr show eth0` | 有上级分配的 IP |
| LAN 静态 IP | `ip addr show br-lan` | 192.168.1.1/24 |
| WiFi 广播 | `iwinfo radio0 info` | 显示 SSID |
| DHCP 服务 | `grep dhcp-range /var/etc/dnsmasq*` | 输出 DHCP 池范围 |
| nftables 规则 | `nft list table inet shellcrash` | 三链规则完整 |
| 策略路由 | `ip rule \| grep 1ed4` | fwmark 0x1ed4 → table 100 |
| TUN 设备 | `ip link show utun` | UP 状态 |
| mihomo 进程 | `ps \| grep mihomo` | 进程存在 |
| 代理测试 | `curl -x 127.0.0.1:7890 https://www.google.com -o /dev/null -s -w '%{http_code}'` | 200 |
| 客户端 DHCP | 手机连 WiFi | 获取 192.168.1.100-249 |

## 八、迁移注意事项

拔下 R3G 接入其他网络时：

- WAN 口 DHCP 自动获取新 IP，无需改配置
- **如果新网络也使用 192.168.1.0/24 网段**，LAN 口 IP 冲突需改网段：
  ```bash
  uci set network.lan.ipaddr='192.168.99.1'
  uci commit network
  /etc/init.d/network restart
  ```
- 代理功能取决于节点在线状态和新网络是否封禁代理协议端口
