=== 接线规则 ===
1. R3G WAN口 → 交换机（上级网络）
2. R3G LAN口 → 留空（严禁接线！）
3. 若WAN+LAN同时接交换机 → 二层环路 → dmesg频繁 blocking/disabled/forwarding

=== IP地址分配 ===
- 主路由/光猫:  192.168.1.1 (DHCP Server for 192.168.1.0/24)
- R3G WAN口:    192.168.1.66 (静态IP，从主路由获取)
- R3G LAN/WiFi: 192.168.1.1 (R3G自身DHCP Server for 192.168.1.0/24)
- 透明代理网关: 192.168.1.1 (默认网关指向R3G)
- 手机:         192.168.1.x (DHCP动态分配)
