========================================
  小米R3G 刷 OpenWrt + Clash 傻瓜指南
  （全程约 30 分钟，请严格按顺序操作）
========================================

【准备工作清单】
  - 本 U 盘（已含全部所需文件）
  - 一根网线
  - 一根牙签或取卡针（用于捅 Reset）
  - 你的机场订阅链接（复制好备用，别给AI）

========================================
  第一步：刷入 Breed 不死引导
========================================

1. 拔掉路由器电源
2. 把本 U 盘插到路由器背面的 USB 口
3. 用牙签按住路由器背面的 Reset 小孔，不要松手
4. 插上电源（Reset 继续按住）
5. 盯着正面指示灯，从黄灯常亮 → 变成黄灯快速闪烁 → 松开 Reset
   （如果等了 30 秒还不闪，拔电源重试，确保 U 盘插紧了）
6. 等待约 2-3 分钟，指示灯最终会变成蓝灯或熄灭
7. 拔掉电源，拔掉 U 盘
   >> Breed 刷入完成！

========================================
  第二步：进入 Breed 刷机界面
========================================

1. U 盘插回电脑，确认文件都在
2. 用网线连接电脑和路由器的 LAN 口（灰色口，不是蓝色 WAN 口）
3. 电脑设置静态 IP（重要！）：

   Windows 操作：
   a. 右键右下角网络图标 → 网络和 Internet 设置
   b. 以太网 → IP 分配 → 编辑
   c. 选择「手动」→ IPv4 打开
   d. 填写：
      IP 地址：192.168.1.10
      子网掩码：255.255.255.0
      网关：192.168.1.1
      DNS：192.168.1.1
   e. 保存

4. 按住路由器 Reset 键，插上电源
5. 等 5 秒后松开 Reset
6. 浏览器打开 http://192.168.1.1
7. 看到 Breed 界面（黑底黄字）→ 成功！

========================================
  第三步：刷入 OpenWrt
========================================

在 Breed 界面操作：

# 3.1 设置环境变量（必须做，否则刷完可能起不来）
   a. 点击左侧「环境变量编辑」
   b. 在「新增」区域：
      名称填：xiaomi.r3g.bootfw
      值填：2
   c. 点击「添加」
   d. 点击页面底部的「保存」

# 3.2 刷入过渡固件
   a. 点击左侧「固件更新」
   b. 「固件类型」选择：小米路由器3G 固件2
   c. 在「固件」那一行点「选择文件」
      → 选 U 盘里的 openwrt-r3g-initramfs.bin
   d. 点「上传」→ 等待进度条走完
   e. 点「更新」→ 确认
   f. 等待路由器重启（约 2 分钟）

# 3.3 刷入正式固件
   a. 浏览器打开 http://192.168.1.1
   b. 看到 OpenWrt 登录界面 → 用户名 root，密码为空，点登录
   c. 顶部菜单：System → Backup / Flash Firmware
   d. 在「Flash new firmware image」区域点「选择文件」
      → 选 U 盘里的 openwrt-r3g-sysupgrade.bin
   e. 点「Flash image」→ 确认
   f. 等待进度条走完，路由器自动重启（约 3 分钟）
   >> OpenWrt 刷入完成！

========================================
  第四步：安装 OpenClash
========================================

1. 浏览器打开 http://192.168.1.1，登录（root / 空密码）
2. 先联网：顶部菜单 Network → Interfaces
   → WAN 点 Edit → Protocol 选 PPPoE（拨号）或 DHCP（光猫已拨号）
   → 填好宽带账号密码后点 Save & Apply
3. 确认能上网后，继续以下操作：

# 安装 luci-compat（OpenClash 依赖）
4. 左侧菜单 System → Software
5. 点「Update lists...」等它跑完
6. 搜索框输入 luci-compat，点安装

# 安装 OpenClash
7. 把 U 盘里的 OpenClash-master 文件夹中
   luci-app-openclash 整个文件夹复制到路由器
   方法：用 WinSCP 等工具连接 192.168.1.1
   或者：在 System → Software 页面搜索 openclash 在线安装

# 推荐在线安装（更简单）：
   - System → Software
   - 搜索 openclash
   - 安装 luci-app-openclash
   - 刷新页面，顶部出现「服务」菜单

========================================
  第五步：配置机场订阅
========================================

1. OpenWrt 左侧菜单：服务 → OpenClash
2. 首次打开点「插件设置」→ 选择模式设置
3. 点「配置订阅」标签
4. 在订阅地址框粘贴你的机场订阅链接
5. 点「添加」→ 点「保存配置」
6. 回到「运行状态」标签，点「开启 Clash」
7. 等 1-2 分钟，看到「运行中」即成功！

========================================
  常见问题
========================================

Q: Breed 页面打不开？
A: 检查电脑 IP 是否设为 192.168.1.10，网线是否插在 LAN 口。

Q: 刷完 OpenWrt 没 Wi-Fi？
A: OpenWrt 默认关闭 Wi-Fi。登录后在 Network → Wireless 里启用。

Q: 刷机过程中断电了怎么办？
A: Breed 是「不死」引导，只要 Breed 刷成功了就不会变砖。
   按住 Reset 通电 5 秒重新进 Breed，重刷即可。

Q: 想恢复官方固件？
A: 去 miwifi.com 下载 R3G 官方固件，进 Breed 直接刷回。
